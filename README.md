# codestudy-prototipo
CodeStudy es un prototipo de plataforma web para estudiantes de software que centraliza recursos y fomenta la práctica constante. Ofrece retos semanales progresivos, revisión de código entre pares simplificada y un panel visual de progreso con gráficos de actividad. Transforma el aprendizaje en un hábito y genera un portafolio de evidencia tangible
